# 步骤 3.3 跨平台兼容性测试

**所属功能**: 整体集成和测试

**目标**: 确保在目标平台上正常运行

**测试平台**: macOS、Windows、Linux、Android

**测试要点**:
- 文件路径处理（使用 path 库，不硬编码分隔符）
- 数据库路径（使用平台标准应用数据目录）
- 纯 Dart 版本控制引擎跨平台兼容性
- File Watcher 跨平台兼容性
- UI 布局自适应（桌面端 vs 移动端）

> ⚠️ **重要变更**: 原文档测试 git2dart 跨平台兼容性。已改用纯 Dart + SQLite 方案，
> 不依赖任何原生动态库，跨平台兼容性更好。详见 `../doc_review_analysis.md`

**测试要求**:
- ✅ macOS：所有功能正常
- ✅ Windows：所有功能正常
- ✅ Linux：所有功能正常
- ✅ Android：所有功能正常
- ✅ 文件路径处理正确
- ✅ UI 布局自适应
