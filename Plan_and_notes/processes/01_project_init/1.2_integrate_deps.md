# 步骤 1.2 集成核心依赖库

**所属功能**: 项目初始化和基础框架搭建

**目标**: 安装项目所需的核心依赖

**要做什么**:
- 在 pubspec.yaml 中添加核心依赖：
  - flutter_riverpod（状态管理）
  - watcher（文件监听）
  - sqflite + sqflite_common_ffi（本地数据库）
  - shared_preferences（偏好设置）
  - file_picker（文件选择）
  - window_manager（桌面窗口管理）
  - crypto（SHA-256 哈希计算，用于版本快照）
- 运行 `flutter pub get`

> ⚠️ **重要变更**: 原文档使用 git2dart，经实测在 Windows 上无法运行（libgit2.dll/libssh2.dll 缺少 OpenSSL 依赖）。已改用纯 Dart + SQLite 方案，详见 `../doc_review_analysis.md`

**测试要求**:
- ✅ `flutter pub get` 无错误
- ✅ 所有依赖库版本兼容
- ✅ 项目仍可正常编译运行

**依赖**: 步骤 1.1
