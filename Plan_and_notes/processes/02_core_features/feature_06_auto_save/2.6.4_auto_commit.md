# 步骤 2.6.4 实现版本自动保存

**所属功能**: 功能6 - 自动保存

**目标**: 将文件变更保存为新的版本快照

**要做什么**:
- 使用纯 Dart 版本控制服务（不再使用 git2dart）
- 读取文件当前内容，计算 SHA-256 哈希值
- 与最新版本快照比对，有变化则创建新快照
- 记录版本元数据（时间戳、文件大小、哈希值）
- 默认使用 AI 生成消息，无 AI 时使用默认消息模板
- 处理保存失败的情况（记录错误日志）
- 更新数据库中的版本记录

> ⚠️ **重要变更**: 原文档使用 git2dart 库进行 Git 操作。经实测 git2dart 在 Windows 上无法运行。
> 已改用纯 Dart + SQLite 方案，将文件内容以 BLOB 形式存储在 SQLite 的 snapshots 表中。
> 详见 `../doc_review_analysis.md`

**测试要求**:
- ✅ 文件变更能正确检测并创建新版本
- ✅ 版本快照内容与原文件一致
- ✅ 版本历史可以查看
- ✅ 所有修改都会保存版本
- ✅ 保存失败时有错误处理

**依赖**: 步骤 2.6.3
