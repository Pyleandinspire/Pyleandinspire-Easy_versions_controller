# 步骤 2.6.1 实现文件系统事件监听

**所属功能**: 功能6 - 自动保存

**目标**: 监听文件变更事件

**要做什么**:
- 使用 watcher 库监听文件变更
- 过滤掉不必要的事件（如临时文件变化、.DS_Store等）
- 记录最后一次修改的时间戳
- 处理文件删除和重命名事件
- **重要**：所有 Service 必须通过 Riverpod Provider 管理，禁止直接实例化

**测试要求**:
- ✅ 修改文件能被检测到
- ✅ 频繁修改不会产生过多事件（有防抖机制）
- ✅ 删除文件能正确响应
- ✅ 重命名文件能正确响应
- ✅ 临时文件变化被过滤掉

**依赖**: 步骤 2.5.2

**父步骤**: 2.5.2_manual.md

> ⚠️ **只有测试通过才可以进行下一步骤**
