# 步骤 2.1.2 实现本地数据库和文件元数据存储

**所属功能**: 功能1 - 添加版本追踪

**目标**: 建立本地数据存储，保存文件元数据和快照记录

**要做什么**:

- 使用 sqflite 创建本地数据库（存放在应用数据目录下）
- 定义两张核心表：

**1. tracked_files 表 — 追踪文件元数据**:
| 字段 | 类型 | 说明 |
|------|------|------|
| id | TEXT | 文件 UUID（唯一标识） |
| file_path | TEXT | 原始文件的绝对路径 |
| file_name | TEXT | 文件名 |
| created_at | TEXT | 添加追踪的时间 |
| updated_at | TEXT | 最后更新时间 |
| snapshot_dir | TEXT | 该文件的快照存储目录路径 |

**2. snapshots 表 — 版本快照记录**:
| 字段 | 类型 | 说明 |
|------|------|------|
| id | TEXT | 快照 UUID |
| file_id | TEXT | 关联的追踪文件 UUID（外键） |
| snapshot_path | TEXT | 快照文件的绝对路径 |
| timestamp | TEXT | 快照创建时间 (ISO 8601) |
| file_size | INTEGER | 文件大小（字节） |
| sha256_hash | TEXT | 文件内容 SHA-256 哈希值 |
| message | TEXT | 版本描述（AI生成或默认） |

- 实现 CRUD 操作接口（增删改查两个表）
- 为每个文件生成唯一标识符（使用 UUID）

**测试要求**:

- ✅ 数据库可以正确创建和打开
- ✅ tracked_files 表 CRUD 操作正常
- ✅ snapshots 表 CRUD 操作正常
- ✅ 同一文件路径生成的 UUID 一致
- ✅ 快照记录与追踪文件正确关联
