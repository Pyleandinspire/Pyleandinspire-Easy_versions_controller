# 步骤 2.1.4 实现文件扫描和定位机制

**所属功能**: 功能1 - 添加版本追踪

**目标**: 处理文件找不到的情况

**要做什么**:
- 检测文件是否存在（启动时和访问时）
- 当文件找不到时，进行智能扫描（先扫描常见目录如桌面、文档、下载，再扩展到全盘）
- 默认扫描5分钟超时（可以在设置进行配置更改）
- 扫描失败时，弹出错误提示对话框
- 提供"放弃追踪"和"提供路径"两个选项
- 不需要显示进度条

**测试要求**:
- ✅ 文件被移动后，软件能检测到找不到
- ✅ 能触发智能扫描机制（优先扫描常见目录）
- ✅ 扫描5分钟后超时
- ✅ 扫描失败后弹出正确的错误提示
- ✅ "放弃追踪"能从列表中移除该文件
- ✅ "提供路径"能重新关联到正确位置
