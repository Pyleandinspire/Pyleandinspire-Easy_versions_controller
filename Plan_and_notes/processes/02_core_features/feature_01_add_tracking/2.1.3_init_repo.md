# 步骤 2.1.3 实现文件版本存储初始化

**所属功能**: 功能1 - 添加版本追踪

**目标**: 为每个追踪文件创建版本存储结构

**要做什么**:
- 在应用数据目录下创建版本存储目录
- 为每个文件创建独立的版本存储子目录
- 将原始文件内容作为初始版本（快照）保存
- 在数据库中记录版本存储路径

> ⚠️ **重要变更**: 原文档使用 git2dart 创建 Git 仓库。经实测 git2dart 在 Windows 上无法运行。
> 已改用纯 Dart + SQLite 方案，用 SQLite 数据库存储文件版本快照，替代 Git 仓库。
> 详见 `../doc_review_analysis.md` 和 `../git2dart_failure_summary.md`

**新方案架构**:
- 版本数据存储在 SQLite 数据库的 `snapshots` 表中
- 每个版本对应一个快照记录（BLOB 存储文件内容）
- 使用 SHA-256 哈希值校验内容完整性

**测试要求**:
- ✅ 版本存储目录正确创建
- ✅ 每个文件有独立的版本记录
- ✅ 版本数据存储在应用数据目录下
- ✅ 初始版本快照成功创建
- ✅ 数据库中记录了版本快照信息
