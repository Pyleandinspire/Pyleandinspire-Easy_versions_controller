# 步骤 2.1.1 实现文件选择对话框

**所属功能**: 功能1 - 添加版本追踪

**目标**: 用户可以选择要追踪的文件，添加后自动创建初始快照

**要做什么**:

- 使用 file_picker 库调用系统文件选择对话框
- 支持多选文件
- 不限制文件类型和大小
- 返回选中的文件路径列表
- 选中文件后，触发后续步骤：数据库记录 → 创建快照目录 → 创建初始快照

**测试要求**:

- ✅ 可以弹出文件选择对话框
- ✅ 可以选择一个或多个文件（任意类型和大小）
- ✅ 返回的文件路径正确且完整
- ✅ 取消选择时不报错
- ✅ 选择文件后自动进入快照初始化流程

**依赖**: 步骤 1.4

**父步骤**: 1.4_theme.md

> ⚠️ **只有测试通过才可以进行下一步骤**
