# 步骤 2.7.3 实现文本文件差异对比（Diff 模块）

**所属功能**: 功能7 - 展示更改

**目标**: 对比两个版本快照的文本内容，高亮显示差异

**适用范围**: 仅文本文件（.txt, .md, .json, .xml, .html, .css, .js, .dart, .py, .java 等）

**要做什么**:

- 实现行级别的 diff 算法（推荐 Myers diff 算法）
- 从快照目录读取两个快照文件的内容
- 逐行比较，标记三种差异类型：
  - 新增行（绿色高亮 `#dcfce7`）
  - 删除行（红色高亮 `#fee2e2`，带删除线）
  - 修改行（黄色高亮 `#fef9c3`）
- 对大文件（> 5000 行）进行分块比较，避免性能问题
- 对比结果以结构化数据返回（行号、类型、内容）

**核心算法**:

```
输入：两个快照文件的文本内容（按行分割）
  1. 调用 Myers diff 算法计算最长公共子序列
  2. 根据 LCS 结果标记每行的类型（新增/删除/不变）
  3. 对相邻的"删除+新增"行对标记为"修改"
  4. 返回带标注的 diff 结果列表
输出：DiffResult[]（每行包含：行号、类型、内容）
```

> ⚠️ **改进说明**: 原文档使用 LCS 算法（复杂度 O(n\*m)）。
> 现直接使用 Myers diff 算法，这是 Git 等工具使用的标准 diff 算法，效率更高。
> 该模块为纯 Dart 实现，跨平台无依赖。

**测试要求**:

- ✅ 能正确计算两个快照版本的差异
- ✅ 新增行标记正确（绿色高亮）
- ✅ 删除行标记正确（红色高亮 + 删除线）
- ✅ 修改行标记正确（黄色高亮）
- ✅ 两个版本完全相同时返回空差异
- ✅ 对 5000 行以上大文件有合理性能（< 2 秒）
- ✅ 二进制文件（非文本）不进入 diff 流程
