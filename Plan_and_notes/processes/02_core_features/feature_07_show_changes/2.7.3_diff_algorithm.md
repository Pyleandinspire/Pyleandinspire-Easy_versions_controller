# 步骤 2.7.3 实现 diff 算法集成

**所属功能**: 功能7 - 展示更改

**目标**: 计算两个版本之间的差异

**要做什么**:
- 使用 Myers diff 算法计算差异（推荐直接实现 Myers diff，而非先 LCS 再优化）
- 从数据库获取两个版本的文件内容快照
- 比较行级别差异
- 标记新增、删除、修改的行
- 对大文件进行性能优化（分块比较）

> ⚠️ **改进说明**: 原文档使用"自实现LCS算法，后续可优化为Myers diff"。LCS 复杂度 O(n*m)，
> Myers diff 才是标准的 diff 算法。建议直接实现 Myers diff，避免二次工作。

**测试要求**:
- ✅ 能正确计算两个版本的差异
- ✅ 新增行标记正确
- ✅ 删除行标记正确
- ✅ 修改行标记正确
- ✅ 无差异时不报错
- ✅ 对大文件（1000行以上）有合理的性能表现
