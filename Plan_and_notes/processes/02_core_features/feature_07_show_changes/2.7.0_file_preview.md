# 步骤 2.7.0 实现中间文件预览面板

**所属功能**: 功能7 - 展示更改

**目标**: 在中间区域预览选中文件的内容，并提供清晰的操作入口

**要做什么**:

- 中间面板自适应宽度，位于左侧文件列表和右侧时间轴之间
- 标题区域：文件图标 + 文件名 + 操作按钮（对比历史版本）
- 文本文件：等宽字体显示文件内容，支持滚动浏览
- 二进制文件（PDF、Excel、图片等）：判断文件类型，二进制文件显示"不支持预览"提示
- 无选中文件时显示占位提示
- 文件不存在时显示错误提示
- **编辑按钮设计**：在预览面板底部以全宽按钮形式展示「编辑此文件」，确保直观易用
  - 按钮使用主题色（accent），带编辑图标 + 文字标签
  - 仅在选中文件时显示
  - 点击跳转到编辑器页面
- **对比按钮**：在标题栏以图标按钮展示（Icons.compare_arrows），跳转到对比视图
- **交互流程**：点击"编辑此文件"按钮时，通过路由参数传递当前选中的文件信息到编辑器页面；点击"对比"按钮时，传递文件信息到对比视图页面

**测试要求**:

- ✅ 选中文本文件时正确显示文件内容
- ✅ 二进制文件显示"不支持预览"提示，不崩溃
- ✅ 无选中文件时显示占位提示
- ✅ 文件不存在时显示错误提示
- ✅ 编辑按钮全宽显示在预览底部，样式醒目
- ✅ 编辑和对比按钮可正常跳转
