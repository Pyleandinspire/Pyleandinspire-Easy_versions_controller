# 步骤 2.7.0 实现中间文件预览面板

**所属功能**: 功能7 - 展示更改

**目标**: 在中间区域预览选中文件的内容，并提供清晰的操作入口

**要做什么**:

- 中间面板自适应宽度，位于左侧文件列表和右侧时间轴之间
- 标题区域：文件图标 + 文件名 + 操作按钮（编辑、对比历史版本、快照预览返回）
- 文本文件：等宽字体显示文件内容，支持滚动浏览
- 二进制文件（PDF、Excel、图片等）：判断文件类型，二进制文件显示"不支持预览"提示
- 无选中文件时显示占位提示
- 文件不存在时显示错误提示
- **编辑按钮设计**：在标题栏以图标按钮展示（Icons.edit_note），点击切换到编辑模式
  - 仅在选中文件且处于预览模式时显示
  - 点击切换到编辑器模式（不跳转页面）
- **对比按钮**：在标题栏以图标按钮展示（Icons.compare_arrows），跳转到对比视图
- **快照预览**：点击时间轴的预览按钮后，在中间面板显示快照内容，标题栏显示返回按钮
  - 预览模式下显示"← 返回当前版本"按钮
  - 快照预览为只读模式，显示快照时间和提交信息
- **交互流程**：点击"编辑"按钮时，在当前页面切换到编辑模式；点击"对比"按钮时，传递文件信息到对比视图页面；点击时间轴预览按钮时，在中间面板显示快照内容
- **快照内容刷新机制**：`_SnapshotPreviewContent` 使用 `StatelessWidget` + `FutureBuilder` 实现
  - 通过 `key: ValueKey(snapshot.id)` 确保切换不同快照时强制重建 widget
  - `FutureBuilder` 声明式加载快照文件内容，自动处理加载中/错误/成功三种状态
  - 解决了 StatefulWidget 复用实例导致 `initState` 不重新执行、内容不刷新的问题

**测试要求**:

- ✅ 选中文本文件时正确显示文件内容
- ✅ 二进制文件显示"不支持预览"提示，不崩溃
- ✅ 无选中文件时显示占位提示
- ✅ 文件不存在时显示错误提示
- ✅ 编辑按钮在标题栏显示，可切换到编辑模式
- ✅ 快照预览在中间面板显示，不跳转新页面
- ✅ 快照预览显示返回按钮可回到当前版本
- ✅ 切换不同快照版本时内容正确刷新
