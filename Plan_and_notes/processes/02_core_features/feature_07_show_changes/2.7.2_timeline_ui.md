# 步骤 2.7.2 实现时间轴 UI 展示

**所属功能**: 功能7 - 展示更改

**目标**: 渲染时间轴视图

**要做什么**:
- 右侧侧边栏竖着显示时间轴列表
- 每条记录显示：版本图标 + 更改摘要 + 时间戳（蓝色强调色）+ 预览按钮
- 版本图标：最新版本使用实心圆点（Icons.fiber_manual_record），历史版本使用空心圆点（Icons.circle_outlined）
- 预览按钮：每条记录右侧显示眼睛图标（Icons.remove_red_eye），点击在中间面板预览该版本
- 悬停时显示完整版本信息
- 支持垂直滑动浏览
- 滚动到底部自动加载更多历史
- 点击列表项弹出操作菜单（预览、对比、回退）

**测试要求**:
- ✅ 时间轴正确渲染
- ✅ 显示信息完整（时间、摘要、图标）
- ✅ 悬停显示完整信息
- ✅ 滑动浏览流畅
- ✅ 自动加载更多历史
- ✅ 预览按钮显示在每条记录右侧
- ✅ 点击预览按钮在中间面板显示快照内容
