# 步骤 2.7.1 实现时间轴数据读取

**所属功能**: 功能7 - 展示更改

**目标**: 从数据库读取版本快照历史

**要做什么**:

- 从 snapshots 表中读取指定文件的所有快照记录
- 关联 tracked_files 表获取文件信息
- 按时间戳倒序排列（最新在前）
- 返回快照列表（时间戳、版本描述、文件大小、哈希值）
- 支持分页加载（避免一次加载过多快照）

**数据库查询**:

```sql
SELECT * FROM snapshots
WHERE file_id = ?
ORDER BY timestamp DESC
```

> ⚠️ **重要变更**: 不再从 git2dart 读取 commit 历史。快照数据存储在 snapshots 表中，
> 实际文件存放在 `snapshots/{file_uuid}/` 目录下。数据库只存元数据，文件内容直接从快照文件读取。

**测试要求**:

- ✅ 能正确读取指定文件的快照历史
- ✅ 时间戳倒序排列正确
- ✅ 快照数量与目录中实际文件数一致
- ✅ 无快照时返回空列表（不报错）
- ✅ 分页加载正常
