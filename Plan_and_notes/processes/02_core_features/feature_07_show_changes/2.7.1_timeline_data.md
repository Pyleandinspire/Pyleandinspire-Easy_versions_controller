# 步骤 2.7.1 实现时间轴数据读取

**所属功能**: 功能7 - 展示更改

**目标**: 从数据库读取版本历史

**要做什么**:
- 从 SQLite 数据库读取指定文件的版本历史
- 解析版本信息（时间戳、版本号、消息、哈希值）
- 按时间倒序排列

> ⚠️ **重要变更**: 原文档使用 git2dart 读取 commit 历史。已改用纯 Dart + SQLite 方案，
> 从 versions 表读取版本记录。详见 `../doc_review_analysis.md`

**测试要求**:
- ✅ 能正确读取版本历史
- ✅ 时间顺序正确（倒序）
- ✅ 版本信息完整（时间、消息、版本号）
- ✅ 无版本记录时不报错

**依赖**: 步骤 2.7.0

**父步骤**: 2.7.0_file_preview.md

> ⚠️ **只有测试通过才可以进行下一步骤**
