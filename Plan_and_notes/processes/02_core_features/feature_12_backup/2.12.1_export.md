# 步骤 2.12.1 实现数据导出

**所属功能**: 功能12 - 数据迁移和备份

**目标**: 将版本快照数据和元数据导出为可移植的备份文件

**要做什么**:

- 打包内容：
  - SQLite 数据库文件（tracked_files 表 + snapshots 表元数据）
  - `snapshots/` 目录下所有快照文件
  - 配置文件（settings）
- 全部打包为 ZIP 压缩文件
- 提供导出进度提示
- 导出完成后提示文件保存位置

> ⚠️ **重要变更**: 不再打包 Git 仓库。导出的是 SQLite 数据库 + 快照文件目录。
> 快照文件按原始目录结构打包，方便导入时恢复。

**测试要求**:

- ✅ 导出功能正常
- ✅ 导出文件包含完整数据（数据库 + 快照文件）
- ✅ 导出进度提示正常
- ✅ 导出完成后提示文件位置
