# 步骤 2.12.2 实现数据导入

**所属功能**: 功能12 - 数据迁移和备份

**目标**: 从备份文件恢复版本快照数据

**要做什么**:

- 选择备份文件（ZIP格式）
- 解压并验证备份文件完整性
- 导入内容：
  - 恢复 SQLite 数据库（合并 tracked_files 和 snapshots 元数据）
  - 恢复 `snapshots/` 目录下的快照文件
- 处理冲突（同名文件、已存在的快照记录 → 提示用户选择覆盖或跳过）
- 提供导入进度提示
- 导入完成后刷新界面

> ⚠️ **重要变更**: 不再导入 Git 仓库。导入的是 SQLite 数据库 + 快照文件目录。
> 快照文件按原始目录结构恢复。

**测试要求**:

- ✅ 导入功能正常
- ✅ 导入后数据完整正确（数据库 + 快照文件）
- ✅ 冲突处理正确（同名文件提示覆盖/跳过）
- ✅ 导入进度提示正常
- ✅ 导入后界面正确刷新
