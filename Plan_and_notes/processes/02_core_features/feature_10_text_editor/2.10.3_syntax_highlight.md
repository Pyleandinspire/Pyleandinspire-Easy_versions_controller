# 步骤 2.10.3 实现语法高亮

**所属功能**: 功能10 - 文本文件编辑

**目标**: 支持常见编程语言的语法高亮，提升代码可读性

**实现方案**: A - 引入 `flutter_highlight` 包

**选型理由**:
- `flutter_highlight` 基于 `highlight.js`，支持 190+ 语言和 80+ 主题
- 纯 Dart 实现，跨平台兼容（Windows/macOS/Linux/Web）
- 社区活跃 (pub.dev 评分 130+)，与 Flutter 生态良好集成
- 包体积约 +300KB（编译后），对应用体积影响小

### 2. 语言自动识别

根据文件扩展名映射到 highlight.js 语言 ID：

```dart
final _languageMap = {
  'dart': 'dart',    'py': 'python',   'js': 'javascript',
  'ts': 'typescript', 'json': 'json',  'xml': 'xml',
  'html': 'html',     'css': 'css',    'md': 'markdown',
  'yaml': 'yaml',    'yml': 'yaml',    'sql': 'sql',
  'sh': 'bash',      'bat': 'dos',     'ps1': 'powershell',
  'java': 'java',    'kt': 'kotlin',   'swift': 'swift',
  'c': 'c',          'cpp': 'cpp',     'h': 'c',
  'rs': 'rust',      'go': 'go',       'rb': 'ruby',
  'php': 'php',      'ini': 'ini',     'toml': 'toml',
  'txt': null,       'log': null,      'csv': null,
};

String? _getLanguage(String fileName) {
  final ext = fileName.split('.').last.toLowerCase();
  return _languageMap[ext];
}
```

### 3. 代码高亮渲染

将 `TextField` 替换为支持语法高亮的 `HighlightView`：

```dart
import 'package:flutter_highlight/flutter_highlight.dart';
import 'package:highlight/languages/all.dart';
import 'package:flutter_highlight/themes/monokai-sublime.dart';

Widget _buildHighlightedEditor() {
  final language = _getLanguage(widget.file.fileName);
  if (language == null) {
    return _buildPlainTextField(); // 纯文本回退
  }
  
  return SingleChildScrollView(
    child: HighlightView(
      _textController.text,
      language: language,
      theme: monokaiSublimeTheme,
      padding: EdgeInsets.all(AppSpacing.sm),
      textStyle: TextStyle(
        fontFamily: 'monospace',
        fontSize: 14,
      ),
    ),
  );
}
```

### 4. 编辑模式 vs 预览模式

- **编辑模式**：保持现有 `TextField`，编辑时不需要实时高亮（性能优化）
- **高亮预览模式**：使用 `HighlightView` 只读展示，切换按钮在工具栏
- 切换时保持滚动位置同步

### 5. 主题支持

```dart
// 预设浅色/深色主题映射
final _themes = {
  'light': 'github',           // 浅色主题
  'dark': 'monokai-sublime',   // 深色主题（默认）
};
```
