# 步骤 2.10.3 实现语法高亮

**所属功能**: 功能10 - 文本文件编辑

**目标**: 支持常见编程语言的语法高亮

**要做什么**:
- 使用 highlight 或 flutter_highlight 库
- 支持语言：Python、JavaScript、TypeScript、Dart、JSON、XML、HTML、CSS、Markdown
- 根据文件扩展名自动选择语言
- 支持主题切换（浅色/深色）

**测试要求**:
- ✅ 各种语言语法高亮正确
- ✅ 自动识别语言正确
- ✅ 主题切换正常
- ✅ 性能良好（大文件不卡顿）
