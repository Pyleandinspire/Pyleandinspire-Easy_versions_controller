# 步骤 2.10.4 实现 Markdown 文件支持

**所属功能**: 功能10 - 文本文件编辑

**目标**: 支持 Markdown (.md) 文件的编辑和实时预览

**实现方案**: A - 引入 `flutter_markdown` 包

**选型理由**:
- `flutter_markdown` 是 Flutter 官方维护的 Markdown 渲染包
- 支持 CommonMark 和 GitHub Flavored Markdown (GFM)
- 纯 Dart 实现，跨平台兼容（Windows/macOS/Linux/Web）
- 包体积约 +200KB（编译后），与 `flutter_highlight` 共享 `markdown` 解析依赖

---

## 实现步骤

### 1. 添加依赖

```yaml
# pubspec.yaml (合并 2.10.3 和 2.10.4 的依赖)
dependencies:
  flutter_markdown: ^0.7.1
  flutter_highlight: ^0.7.0
  highlight: ^0.7.0
  markdown: ^7.2.2
```

### 2. 三视图模式切换

仅对 `.md` / `.markdown` 文件启用的视图切换：

```dart
enum MarkdownViewMode { edit, preview, split }
```

| 模式 | 说明 |
|------|------|
| 编辑模式 | 纯文本 TextField 编辑（当前行为），左侧行号 |
| 预览模式 | `Markdown` widget 渲染 HTML，只读 |
| 分屏模式 | 左侧编辑区 + 右侧预览区，同步滚动 |

### 3. Markdown 预览渲染

```dart
import 'package:flutter_markdown/flutter_markdown.dart';

Widget _buildMarkdownPreview() {
  return Markdown(
    data: _textController.text,
    selectable: true,
    extensionSet: md.ExtensionSet.gitHubFlavored,
    styleSheet: MarkdownStyleSheet.fromTheme(Theme.of(context)),
  );
}
```

### 4. 分屏布局

```
┌──────────────────────────────────────────────────┐
│  [←]  README.md ●  [编辑|预览|分屏] [撤销] [重做]│ ← 工具栏
├──────────────────────┬───────────────────────────┤
│  1 │ # 标题          │ # 标题                    │
│  2 │ 正文内容...      │ 正文内容...               │
│  3 │ ```dart          │ (渲染后的效果)            │
│                      │                           │
│  左侧: TextField     │  右侧: Markdown           │
│  (编辑)              │  (预览)                   │
├──────────────────────┴───────────────────────────┤
│ 行 1, 列 5 │ 字数 12 │ 行数 3 │ [MD] 未保存      │
└──────────────────────────────────────────────────┘
```

### 5. 工具栏按钮

当文件扩展名为 `.md` 时，工具栏新增：

```dart
// 视图模式切换按钮组
ToggleButtons(
  isSelected: [mode == edit, mode == preview, mode == split],
  onPressed: (index) => setState(() => _mode = MarkdownViewMode.values[index]),
  children: [
    Tooltip(message: '编辑', child: Icon(Icons.edit)),
    Tooltip(message: '预览', child: Icon(Icons.visibility)),
    Tooltip(message: '分屏', child: Icon(Icons.chrome_reader_mode)),
  ],
)
```
