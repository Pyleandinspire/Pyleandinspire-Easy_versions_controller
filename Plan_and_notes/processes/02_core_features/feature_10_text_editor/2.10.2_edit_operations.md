# 步骤 2.10.2 实现基本编辑操作

**所属功能**: 功能10 - 文本文件编辑

**目标**: 实现撤销/重做、查找替换、保存流程等核心编辑操作

**实现方案**: 纯 Dart 实现，不依赖外部库。撤销/重做基于 `List<String>` 历史栈，查找替换基于字符串操作。

---

## 已实现

| 功能         | 说明                                                                                |
| ------------ | ----------------------------------------------------------------------------------- |
| 撤销/重做    | `List<String>` 历史栈，最多 50 步，支持连续撤销/重做                                |
| 查找替换     | `Ctrl+F` 切换查找替换栏，支持查找下一个（循环）、替换当前、全部替换                 |
| 文件读写     | `dart:io File.readAsString()` / `writeAsString()`                                   |
| 保存流程     | 写入文件 → AI 生成 commit message → `SnapshotService.createAutoSnapshot` → 更新历史 |
| 重复快照过滤 | `SnapshotService` 内部通过 SHA-256 哈希对比，内容无变化时跳过                       |
| 修改检测     | 实时监听 `TextEditingController`，有修改时显示红色圆点和黄色「未保存」              |
| 编码处理     | UTF-8 默认编码（`File.readAsString()` / `writeAsString()` 默认 UTF-8）              |

## 保存流程

```
用户 Ctrl+S / 点击 FAB
  → 检查 _hasChanges (无变化则跳过)
  → editorService.writeFile(filePath, content)  // 写入原文件
  → aiCommitService.generateAutoSaveMessage()   // AI 生成快照信息
  → snapshotService.createAutoSnapshot(message)  // 创建版本快照
  → _saveToHistory()                             // 更新撤销历史
  → _hasChanges = false                          // 清除修改标记
  → SnackBar: "保存成功，已创建新版本快照"
```

## 查找替换流程

```
Ctrl+F → 显示查找替换栏
  → 输入查找文本 → 回车 / 点击「查找下一个」
    → 从光标位置向后搜索 → 找到则选中 → 到末尾则循环到开头
  → 输入替换文本 → 点击「替换当前」
    → 替换选中匹配项 → 自动跳到下一个
  → 点击「全部替换」
    → replaceAll 全部替换 → 写入历史
```
