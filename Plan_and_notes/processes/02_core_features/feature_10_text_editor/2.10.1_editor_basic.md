# 步骤 2.10.1 实现编辑器基础组件

**所属功能**: 功能10 - 文本文件编辑

**目标**: 创建基础文本编辑器，提供轻量、跨平台的纯文本编辑能力

**实现方案**: 保持 Flutter 原生 `TextField`，不引入第三方编辑器组件，确保零额外依赖和全平台兼容。编辑器集成到主页面中间区域，与预览模式切换。

---

## 已实现

| 功能 | 说明 |
|------|------|
| 编辑器集成 | 嵌入主页面中间区域，与预览模式通过顶部按钮切换 |
| 编辑入口 | 文件预览面板顶部编辑图标按钮点击切换 |
| 顶部工具栏 | 返回预览按钮、文件名、红色修改指示圆点、语法高亮切换、Markdown视图切换、外部程序打开、撤销、重做 |
| 行号显示 | 左侧固定 50px 宽行号区域，与编辑区域同步滚动 |
| 编辑区域 | `TextField(maxLines: null)` 无边框设计，`AppColors.primary` 背景 |
| 底部状态栏 | 行号/列号、字数、行数、字符数、文件类型标签（蓝色）、未保存状态（黄色） |
| 快捷键 | `Ctrl+S` 保存, `Ctrl+F` 打开查找替换栏 (via `CallbackShortcuts`) |
| 版本集成 | 保存时通过 `SnapshotService.createAutoSnapshot` 创建快照 + AI 生成提交信息 |
