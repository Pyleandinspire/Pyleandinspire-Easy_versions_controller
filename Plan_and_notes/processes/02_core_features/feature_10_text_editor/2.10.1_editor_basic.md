# 步骤 2.10.1 实现编辑器基础组件

**所属功能**: 功能10 - 文本文件编辑

**目标**: 创建基础文本编辑器

**要做什么**:
- 创建文本编辑器页面（独立路由），包含顶部工具栏 + 编辑区域 + 底部状态栏
- 使用 TextField 或 CodeEditor 组件
- 顶部工具栏按钮：保存、撤销、重做、加粗、斜体、下划线、标题级别、无序列表、有序列表、代码块、引用、链接
- 加粗、斜体、下划线等富文本格式化
- 支持多标签页管理（打开多个文件时以标签页形式展示）
- 底部状态栏：行号、列号、字数统计、文件类型
- 多标签页管理（打开多个文件时以标签页形式展示）
- 在文件预览面板底部以全宽蓝色按钮「编辑此文件」展示
- 点击后通过 Navigator 跳转到编辑器页面
