# 步骤 2.10.6 实现 DOCX 文件支持

**所属功能**: 功能10 - 文本文件编辑

**目标**: 支持 DOCX 文件的高保真预览和通过系统程序编辑

---

## 技术方案

### DOCX 预览: 方案 B - `docx_file_viewer`

**选型理由**:
- `docx_file_viewer` 1.0.1，已验证发布者，15 赞，全平台支持（Windows/macOS/Linux/Android/iOS）
- 纯 Flutter Widget 原生渲染，非 WebView 或 PDF 转换
- 高保真渲染：段落、表格、列表、图片、形状、页眉页脚、脚注/尾注
- 支持缩放（捏合）、文本搜索、文本选择/复制
- 支持连续滚动和分页两种视图模式
- 支持嵌入字体（OOXML 字体反混淆）
- 依赖 `docx_creator`（纯 Dart）+ `url_launcher`，无原生依赖

**依赖清单**:
```yaml
# pubspec.yaml 新增
dependencies:
  docx_file_viewer: ^1.0.1
  url_launcher: ^6.3.1
```

**传递依赖**: `docx_creator`（通过 docx_file_viewer 自动引入）

### DOCX 编辑: 方案 C - 系统默认程序打开

**选型理由**:
- DOCX 格式极其复杂（样式、表格、图片、批注、修订等），Flutter 生态无成熟的所见即所得编辑器
- `docx_viewer_plus` 虽有编辑功能但不支持 Windows 平台
- 使用系统默认程序（Word / WPS / LibreOffice）编辑是最可靠的方式
- 与 PPTX 方案保持一致，用户体验统一

**实现方式**:
- 复用已有的 `platform_utils.dart` 中的 `openFileWithDefaultApp` 方法
- 在预览区顶部工具栏添加「用默认程序打开」按钮
- 类似 PPTX 的处理逻辑

## 实现要点

### 1. 文件类型判断

```dart
bool _isDocxFile(String filePath) {
  final ext = filePath.split('.').last.toLowerCase();
  return ext == 'docx';
}
```

### 2. DOCX 预览组件

```dart
import 'package:docx_file_viewer/docx_file_viewer.dart';

Widget _buildDocxPreview() {
  return DocxView.path(
    widget.file.filePath,
    config: DocxViewConfig(
      enableSearch: true,
      enableZoom: true,
      enableSelection: true,
      pageMode: DocxPageMode.continuous,
    ),
  );
}
```

### 3. 系统程序打开

```dart
// 复用已有的 platform_utils.dart
import 'package:easy_versions_controller/utils/platform_utils.dart';

void _openWithDefaultApp() {
  openFileWithDefaultApp(widget.file.filePath);
}
```

### 4. 工具栏按钮

DOCX 文件预览时，工具栏显示「用默认程序打开」按钮（与 PPTX 一致）。
