# 步骤 2.5.1 实现首次使用引导（onboarding）

**所属功能**: 功能5 - 展示使用说明

**目标**: 帮助新用户快速了解软件功能

**要做什么**:
- 使用 shared_preferences 检测是否首次使用
- 创建全屏引导流程（欢迎页 → 功能概览 → 操作引导 → 完成页）
- 支持左右滑动切换
- 支持跳过引导
- 完成后标记已引导
- **重要**：必须在 main.dart 中集成 Onboarding 判断逻辑，首次使用时自动跳转到 OnboardingPage

**测试要求**:
- ✅ 首次打开软件时显示引导
- ✅ 引导流程清晰、简洁
- ✅ 可以左右滑动切换页面
- ✅ 可以跳过引导
- ✅ 完成引导后再次打开不再显示

**依赖**: 步骤 2.4.2

**父步骤**: 2.4.2_auto_save_time.md
