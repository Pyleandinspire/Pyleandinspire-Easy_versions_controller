# 步骤 2.8.1 实现 API 配置界面

**所属功能**: 功能8 - AI 生成 commit 消息

**目标**: 用户配置 AI 服务连接信息

**要做什么**:
- 创建设置页面中的 API 配置区域
- 输入框：API 地址、API Key（密码框）、模型名称
- API 地址默认值：Docker 本地部署地址（如 `http://localhost:11434/v1/chat/completions`）
- 保存到 shared_preferences（API Key 加密存储）
- 验证连接按钮（测试 API 是否可用）
- 连接状态指示器（成功/失败/未配置）

**测试要求**:
- ✅ API 配置可以保存和读取
- ✅ API Key 加密存储
- ✅ 验证连接功能正常
- ✅ 连接状态指示器正确显示
- ✅ 默认值正确填充

**依赖**: 步骤 2.7.6

**父步骤**: 2.7.6_version_rollback.md

> ⚠️ **只有测试通过才可以进行下一步骤**
