# 步骤 2.11.4 实现图片预览

**所属功能**: 功能11 - 多格式文件预览

**目标**: 在中间面板预览图片文件

**要做什么**:
- 使用 Image.file 加载本地图片
- 支持常见图片格式：PNG、JPG、JPEG、GIF、BMP、WebP、SVG、ICO
- 居中展示，适应窗口大小

**实现要点**:
- 图片通过 `Image.file` 直接渲染，`fit: BoxFit.contain` 适应窗口
- 图片格式通过扩展名白名单判断
- 保持当前实现，无需额外依赖

**测试要求**:
- ✅ 图片文件可以正常预览
- ✅ 适应窗口功能正常
- ✅ 各种格式图片都能正确显示

**依赖**: 步骤 2.11.3

**父步骤**: 2.11.3_pptx.md

> ⚠️ **只有测试通过才可以进行下一步骤**
