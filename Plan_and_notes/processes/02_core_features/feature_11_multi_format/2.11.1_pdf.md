# 步骤 2.11.1 实现 PDF 预览

**所属功能**: 功能11 - 多格式文件预览

**目标**: 在中间面板预览 PDF 文件

**要做什么**:
- 集成 pdfrx 库（^2.4.3），基于 PDFium 引擎，全平台支持
- 使用 `PdfViewer.uri` 加载本地 PDF 文件
- 自带缩放、滚动、翻页、文本选择、文本搜索功能
- 在中间预览面板嵌入 PdfViewer 组件

**技术选型理由**:
- pdfrx 是 Flutter 生态中最成熟的 PDF 方案（332 赞，Verified Publisher）
- 底层使用 Google PDFium 引擎（Chromium 同款），渲染质量高
- 支持 Android / iOS / Windows / macOS / Linux / Web 全平台
- 活跃维护（最新 2.4.3，5 天前更新）
- API 简洁：`PdfViewer.uri(...)` 一行即可加载本地文件

**Windows 注意**:
- 构建时需要开启 Windows 开发者模式（pdfrx 构建过程使用符号链接）

**测试要求**:
- ✅ PDF 文件可以正常预览
- ✅ 缩放功能正常
- ✅ 翻页/滚动功能正常
- ✅ 文本选择功能正常
