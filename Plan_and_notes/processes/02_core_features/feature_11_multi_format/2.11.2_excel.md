# 步骤 2.11.2 实现 Excel 表格预览

**所属功能**: 功能11 - 多格式文件预览

**目标**: 在中间面板预览 Excel 文件

**要做什么**:

- 自定义 XLSX 解析：使用 archive 库解压 ZIP + xml 库解析内部 XML
- 在中间预览面板以 DataTable 形式展示数据
- 支持多工作表切换（TabBar 切换 sheet）
- 基本单元格数据展示（不要求完全还原格式）

**技术选型理由**:

- excel 库依赖 archive ^3.x，与 pdfrx 的 archive ^4.x 冲突，无法共存
- XLSX 本质是 ZIP 压缩的 XML 文件，结构简单，自定义解析可行
- 利用已有的 archive 库解压 + xml 库解析，无需额外依赖
- 轻量可控，只提取需要的数据（工作表名 + 单元格内容）

**实现要点**:

- 创建 `XlsxParserService` 解析 XLSX 文件
- 解析 `xl/workbook.xml` 获取工作表名称列表
- 解析 `xl/sharedStrings.xml` 获取共享字符串表
- 解析 `xl/worksheets/sheet*.xml` 获取单元格数据
- 顶部 TabBar 切换不同工作表
- DataTable 展示当前工作表数据（首行作为表头）
- 限制最大显示行列数（100行 × 50列），超出部分截断提示

**测试要求**:

- ✅ Excel 文件可以正常预览
- ✅ 数据展示正确
- ✅ 多工作表切换正常
- ✅ 大文件有合理性能（不崩溃）
