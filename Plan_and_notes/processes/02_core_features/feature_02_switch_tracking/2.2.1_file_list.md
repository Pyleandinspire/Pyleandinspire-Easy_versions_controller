# 步骤 2.2.1 实现文件列表展示

**所属功能**: 功能2 - 切换版本追踪

**目标**: 展示所有被追踪的文件

**要做什么**:
- 从本地数据库读取文件列表
- 左侧面板显示文件列表（文件名、路径省略显示、最后修改时间）
- 顶部搜索框，支持按文件名搜索过滤
- 当前选中文件高亮显示
- 底部"+ 添加文件"按钮

**测试要求**:
- ✅ 能正确显示所有已添加的文件
- ✅ 文件信息显示正确（名称、路径、时间）
- ✅ 搜索框能正确过滤文件列表
- ✅ 选中文件高亮显示
- ✅ "+ 添加文件"按钮可点击
