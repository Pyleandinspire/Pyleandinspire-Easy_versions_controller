# 步骤 2.3.1 实现删除版本追踪

**所属功能**: 功能3 - 删除版本追踪

**目标**: 用户可以从追踪列表中移除文件

**要做什么**:
- 在文件列表项上添加删除图标（或右键菜单）
- 点击后弹出确认弹窗："是否删除对此文件的版本追踪？"
- 提供两个选项：
  - "仅移除追踪"：从列表中移除，保留历史版本数据（快照数据不删除）
  - "完全删除"：移除追踪并删除所有历史版本数据（快照数据也删除）
  - "取消"：不做任何操作
- 从数据库中删除对应记录
- 如果选择"完全删除"，同时删除对应的版本快照数据
- 删除后刷新文件列表

**测试要求**:
- ✅ 删除图标/右键菜单可以正常触发
- ✅ 弹出确认弹窗，显示两个选项
- ✅ "仅移除追踪"：从列表中移除，历史版本数据仍存在
- ✅ "完全删除"：从列表中移除，版本快照数据被删除
- ✅ "取消"：不做任何操作
- ✅ 删除后文件列表正确刷新
