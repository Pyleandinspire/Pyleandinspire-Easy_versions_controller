# 步骤 4.1 打包和发布

**所属功能**: 发布准备

**目标**: 将应用打包为各平台安装文件

**要做什么**:
- macOS：打包为 .dmg 文件，配置代码签名
- Windows：打包为 .exe 安装程序（使用 Inno Setup 或 NSIS）
- Linux：打包为 .AppImage 或 .deb
- Android：打包为 .apk 文件
- 配置应用图标、版本号、名称
- 生成发布说明 (Release Notes)

**测试要求**:
- ✅ macOS .dmg 可以正常安装和运行
- ✅ Windows .exe 可以正常安装和运行
- ✅ Linux .AppImage 可以正常运行
- ✅ Android .apk 可以正常安装和运行
- ✅ 应用图标正确显示
- ✅ 版本号信息正确

**依赖**: 步骤 3.3

**父步骤**: 3.3_cross_platform_test.md

> ⚠️ **只有测试通过才可以进行下一步骤**
