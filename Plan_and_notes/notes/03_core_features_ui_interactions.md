# 阶段三开发总结：功能2-5 - 切换/删除/设置/引导

**完成日期**: 2026-06-03

**核心目标**: 实现文件切换、删除追踪、设置页面、引导页面等交互功能。

---

## 步骤 2.2.1 - 文件列表展示

**新增功能**:
- 添加搜索框（TextField），支持按文件名实时过滤
- 搜索前缀图标 + placeholder 提示文字
- 空搜索结果时显示空状态

## 步骤 2.2.2 - 文件切换交互

**已有功能**（验证通过）:
- 点击文件列表项切换到对应文件，选中项高亮
- 选中项视觉反馈：蓝色背景 + 加粗字体
- 切换时自动更新 `updatedAt` 时间戳
- 文件不存在时弹出 FileNotFoundDialog

## 步骤 2.3.1 - 删除版本追踪

**新增功能**:
- 文件列表项右侧添加删除图标按钮
- 确认删除弹窗，提供三个选项：
  - **取消**：不做任何操作
  - **仅移除追踪**：从数据库删除记录，保留快照文件
  - **完全删除**：删除数据库记录 + 删除所有快照文件
- `removeFile()` 方法新增 `deleteSnapshots` 参数

## 步骤 2.4.1 - 设置页面布局

**已有功能**（验证通过）:
- 设置弹窗通过顶部齿轮图标打开
- 设置分类：通用、自动保存、AI 配置
- 使用 `shared_preferences` 持久化设置

## 步骤 2.4.2 - 自动保存时间设置

**已有功能**（验证通过）:
- 自动保存间隔（默认 5 分钟）
- 延迟时间（默认 10 秒）
- 设置值通过 `SettingsService` 管理

## 步骤 2.5.1 - 首次使用引导

**已有功能**（验证通过）:
- `_AppEntryPoint` 在 `main.dart` 中判断首次使用
- `OnboardingPage` 全屏引导流程
- 完成后标记 `hasShownOnboarding`，不再显示

## 步骤 2.5.2 - 使用说明书

**已有功能**（验证通过）:
- 顶部"简控"按钮 + 帮助图标
- `HelpDialog` 弹窗（左侧目录 + 右侧内容 + 搜索 + AI 输入）
