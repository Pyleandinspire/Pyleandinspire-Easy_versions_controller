## 二、新增实现

### 2.10.1 补充 — 底部状态栏
- 行号 / 列号（实时显示光标位置）
- 字数统计、行数、字符数
- 文件类型标签（蓝色背景）
- 未保存状态指示（黄色 "未保存" 文字）

### 2.10.1 补充 — Ctrl+S 快捷键
- 使用 `CallbackShortcuts` + `Focus` 包裹 Scaffold
- `Ctrl+S` 调用 `_saveFile()`
- `Ctrl+F` 打开查找替换栏

### 2.10.2 补充 — 查找/替换功能
- `Ctrl+F` 切换查找/替换栏（顶部显示）
- 查找输入框 + 替换输入框
- 查找下一个（支持循环查找，自动选中文本）
- 替换当前（选中匹配项时替换）
- 全部替换
- 关闭按钮

### 2.10.3/2.10.4 延后原因
- 语法高亮需 `flutter_highlight` 外部依赖，且需将 `TextField` 替换为代码编辑器组件
- Markdown 预览需 `flutter_markdown` 外部依赖
- 这两个功能是 UI 增强，不影响核心版本控制功能，延后到后续版本
