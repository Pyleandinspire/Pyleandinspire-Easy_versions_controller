**完成日期**: 2026-06-03

## 功能7 - 展示更改 (2.7.0-2.7.6)

### 2.7.0 文件预览面板
- 中间面板显示选中文件内容
- 文本文件等宽字体显示，二进制文件提示"不支持预览"
- 编辑/对比按钮可跳转

### 2.7.1 时间轴数据
- 新增 `snapshot_timeline_provider.dart`
- 从数据库读取快照记录，按时间戳倒序排列

### 2.7.2 时间轴 UI
- 右侧面板显示快照时间轴列表
- 每条记录显示：图标 + 描述 + 时间戳
- 最新快照用实心圆点标记

### 2.7.3 差异对比算法
- `diff_service.dart` 使用 LCS 算法实现行级 diff
- 支持三种差异类型：新增(绿)、删除(红)、修改(黄)

### 2.7.4 对比视图 UI
- 双栏并排布局，左右同步滚动
- 顶部显示快照版本 vs 当前文件
- 支持并排/统一视图切换

### 2.7.5 对比导航
- 上一个/下一个差异按钮
- 差异计数显示

### 2.7.6 版本回退
- `snapshot_service.dart` 新增 `restoreSnapshot` 方法
- 回退流程：保存当前文件 → 覆盖原文件 → 创建回退记录
- 确认弹窗提示版本信息

## 功能8-9 - AI 配置与助手
