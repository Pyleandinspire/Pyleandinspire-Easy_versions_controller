### 新增文件

**`lib/services/backup_service.dart`**

- 导出：使用 `archive` 包打包 SQLite 数据库 + `snapshots/` 目录 + settings.json 为 ZIP 文件
- 导入：解压 ZIP，恢复数据库和快照文件到对应目录
- 使用 `file_picker` 选择导出位置和导入文件
- 导出流程：选择位置 → 创建 ZIP → 打包所有数据 → 完成
- 导入流程：选择文件 → 确认提示 → 解压到临时目录 → 复制数据 → 清理临时目录
- 设置文件导入后被忽略（避免覆盖用户当前配置）

### 修改文件

**`lib/views/settings_dialog.dart`**

- 在"通用设置"分类下新增"数据管理"区域
- "导出数据"按钮（蓝色，带下载图标）
- "导入数据"按钮（灰色，带上传图标）
- 导入前弹出确认对话框，提示将覆盖当前数据
- 操作结果通过 SnackBar 提示

### 新增依赖

- `archive: ^4.0.7` — ZIP 打包/解压
