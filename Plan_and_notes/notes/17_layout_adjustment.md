# 三栏布局调整开发笔记

## 调整背景

根据用户提供的设计图，需要将原有的两栏布局（左侧文件列表 + 右侧时间轴）调整为三栏布局：
- 左侧：文件列表
- 中间：文件预览区
- 右侧：时间轴（竖着显示）

## 布局结构

```
┌─────────────────────────────────────────────────────────────────┐
│                        顶部导航栏                               │
├──────────────┬──────────────────────────┬──────────────────────┤
│   左侧面板    │         中间区域          │      右侧面板        │
│  文件列表     │       文件预览区          │     时间轴           │
│   (300px)    │       (自适应宽度)        │    (250px)          │
│              │                          │                     │
│              │                          │                     │
│              │                          │                     │
│              │                          │                     │
├──────────────┴──────────────────────────┴──────────────────────┤
│                        底部状态栏                               │
└─────────────────────────────────────────────────────────────────┘
```

## 修改内容

### 1. 主布局结构修改 (`main_page.dart:34-56`)

将原来的两栏布局修改为三栏布局：
- 左侧：`_buildLeftPanel()` - 保持原有文件列表功能
- 中间：新增 `_buildCenterPanel()` - 文件预览区
- 右侧：`_buildRightPanel()` - 调整为固定宽度250px

### 2. 新增中间面板组件

#### `_buildCenterPanel()` (第272-281行)
- 无文件选中时显示占位提示
- 有文件选中时显示文件预览

#### `_buildNoSelectionPreview()` (第283-296行)
- 显示文件预览图标和提示文字

#### `_buildFilePreview()` (第298-338行)
- 显示文件名和操作按钮（编辑、对比）
- 加载并显示文件内容

### 3. 新增文件预览内容组件

#### `_FilePreviewContent` (第558-638行)
- 异步加载文件内容
- 显示加载状态和错误提示
- 使用等宽字体显示文本内容

### 4. 右侧时间轴调整

#### `_buildRightPanel()` (第340-374行)
- 固定宽度为250px
- 使用浅灰色背景区分面板
- 添加左侧边框分隔
- 紧凑的标题栏设计

#### `_buildNoSelectionTimeline()` (第544-555行)
- 简化的无选择状态提示

## 注意事项

1. macOS沙盒权限问题：需要在 entitlements 文件中配置文件访问权限
2. 大文件预览性能：当前实现为一次性读取整个文件内容，对于超大文件可能需要优化
3. 文件类型支持：当前仅支持纯文本文件预览

## 后续优化建议
