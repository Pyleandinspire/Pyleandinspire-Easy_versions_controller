## 四、开发过程中遇到的主要问题和解决方法

### 问题1：git2dart API 兼容性
- **描述**：git2dart 0.4.0 版本的部分 API 与文档不一致，diff 相关方法不存在或签名不同
- **解决方法**：放弃使用 git2dart 的 diff API，改为手动获取两个版本的文件内容，使用 LCS（最长公共子序列）算法自行实现差异计算
- **影响**：DiffService 完全自研，不依赖 git2dart 的 diff 功能

### 问题2：Riverpod v3 破坏性变更
- **描述**：Riverpod v3 移除了 ChangeNotifierProvider，StateProvider 使用方式也发生变化
- **解决方法**：
  - ChangeNotifierProvider → 改用 Provider
  - StateProvider → 改用 ConsumerStatefulWidget 管理状态
  - 使用 AsyncNotifier 处理异步状态

### 问题3：macOS 沙盒权限
- **描述**：macOS 应用默认启用沙盒，无法访问用户文件
- **解决方法**：在 DebugProfile.entitlements 和 Release.entitlements 中添加 `com.apple.security.files.user-selected.read-write` 权限

### 问题4：布局从两栏改为三栏
- **描述**：原设计为左右两栏，用户要求将时间轴放到侧边竖着显示，中间用来预览文件
- **解决方法**：重构 main_page.dart，将 Row 从两个子组件扩展为三个（左侧文件列表 + 中间预览 + 右侧时间轴），右侧改为固定宽度 250px

### 问题5：图标和常量错误
- **描述**：`Icons.file_preview` 不存在、`TextDirection.ltr` 常量名错误
- **解决方法**：替换为 `Icons.file_open`，删除不必要的 textDirection 属性
